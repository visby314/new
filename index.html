    保存先（GitHub の鍵）

    保存先は GitHub の非公開リポジトリ study-inbox です。前のアプリと同じ場所・同じ形で保存するので、前のアプリと並べて使えます。鍵はこの端末の中だけに保存されます。

    時間割
    知らせ（コマの始まりと終わり）

    このアプリが知らせを出せるのは、アプリを開いている間だけです（PCのブラウザなら、タブを開いたままにしておけば裏にあっても出ます）。iPhone でアプリを閉じている間も知らせてほしいときは、下のボタンで時間割をカレンダーに入れてください。カレンダーの通知として、コマの始まりに鳴ります。

    教材ノルマ

    締め切りの日まで、残りの量を毎日同じだけ進めるとしたときの量が「今日のノルマ」になります。朝4時に切り替わります。

    目標と科目

    日付の区切りは朝4時です。夜中の1時に勉強した分は、前の日に入ります。

    数え始める日を空けておくと、最初に記録した日から数えます。締め切り日の前日までを目標の期間にします。

    科目

    名前を変えても、前の記録はその科目のまま残ります。消した科目の記録も残ります。

    過去問の試験と配点

    東大の合計見込み（550点満点）を出すときに、共テ110点分をこの割合で足します。

    大問は1行に1つ、「名前:満点」の形で書きます。例：第1問:20

    「今日」に出す講座

    チェックを外した講座は「今日」の画面に出ません（記録の講座の表には出ます）。この設定はこの端末だけのものです。

    このアプリについて

    勉強時間・教材ノルマ・講座チェックリスト・過去問の得点・間違えた問題の受け箱を1つにまとめたアプリです。記録は前のアプリと同じファイル（study-inbox の records/ と inbox/）に入るので、前のアプリで付けた記録もそのまま出ますし、前のアプリに戻っても記録は残ります。時間割だけは新しいファイル（records/timetable.json）に入ります。
